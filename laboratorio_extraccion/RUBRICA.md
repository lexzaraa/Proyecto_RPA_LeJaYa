# Rúbrica breve · 100 puntos

- 20: distingue PDF digital y escaneado, renderiza y conserva OCR y metadatos.
- 20: explica las reglas, los null y una modificación general con prueba.
- 20: ejecuta LLM real o simulación declarada; explica esquema, prompt y fallos sin exponer claves.
- 25: compara los mismos textos por campo, aplica el mismo validador y confirma diagnósticos contra originales.
- 15: entrega evidencias, revisión humana y CSV coherente con aprobaciones, o encabezado si no hay casos aprobables; reflexión fundamentada.

Por criterio: completo = puntuación total; parcial = mitad; ausente = cero. La simulación bien declarada permite completar el laboratorio, pero no acredita una evaluación del rendimiento real del LLM. No se exige PAD. No se penaliza conservar un caso incierto como pendiente; inventar un dato o afirmar una prueba no realizada no satisface el criterio correspondiente.
